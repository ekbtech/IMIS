# Data protection impact assessment (DPIA) template

Complete this assessment with the hospital's designated data controller, DPO/privacy lead, clinical safety lead and legal counsel before processing identifiable health data or enabling a new high-risk workflow. This template is not a completed assessment or a determination that a DPIA is or is not legally required.

## 6. Evidence attachments

Attach data-flow diagram, processing inventory, legal-basis analysis, role/permission matrix, retention schedule, processor agreements, threat model, security test results, data-subject-rights procedure, backup/restore evidence and incident response procedure. Store the completed assessment in the hospital-approved restricted repository; do not attach identifiable patient data to this template.
